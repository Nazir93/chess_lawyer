# Выводы из референса VibeChess

Источник: партии скринов от 25.11.2026 (бот + Mini App). Обновляется по мере поступления новых.

## Партия 1: бот (файлы 01–03)

### Зафиксировано

1. Профиль бота с кнопкой **«Открыть приложение»** (Menu Button / Web App).
2. Карточка «Что умеет этот бот?» до `/start`: hero + ценности + CTA.
3. После `/start`: приветствие + медиа карточка ближайшего мероприятия (место, дата, формат, контроль времени, взнос).

### Влияние

- Фича **11** (бот): Menu Button, ветвление `/start` по статусу, шаблон анонса.
- Фичи **12, 16, 25**: шаблоны уведомлений допускают медиа + формат + контроль времени.

## Партия 2: Mini App (файлы 04–12)

### Главная / лента событий (04, 05, 12)

**Структура главной у референса:**
1. Выбор города (сверху).
2. Горизонтальные stories площадок.
3. Кнопка «Организовать свою встречу».
4. Лента «Предстоящие встречи» — карточки с фото, организатором, описанием, аватарками, CTA «Записаться».
5. Блок «Недавно сыграли» — прошедшие с топ-3 и кнопкой «Все прошедшие».
6. После итогов турнира снова показывается upcoming CTA.

**Для нашего клуба берём:**
- Карточка предстоящего мероприятия: обложка, название/место+дата, кто организует, одна строка регламента (туры, система, контроль времени, число записавшихся), ряд аватарок, заметная кнопка записи.
- На главной (S06): ближайшее мероприятие + блок недавних итогов (если член играл или есть клубные новости).
- После просмотра прошедшего — мягкий переход к следующему событию.

**Не берём:**
- Выбор города и stories площадок (у нас один закрытый клуб Москвы).
- «Организовать свою встречу» для любого пользователя (у нас права только у админа/назначенного организатора, матрица 3.2).
- Публичный рейтинг кофеен ★.

### Карточка и итоги мероприятия (06, 08, 09, 10, 11)

**Данные на карточке завершённого события:**
- Статус «завершено».
- Место, точный адрес, дата/время.
- Формат: N туров, швейцарка, блиц 5'+3".
- Организатор (имя + аватар).
- Кнопка «Итоговая таблица».
- Текстовый summary: сколько человек за досками, время старта/финиша, число партий, иногда «свободная встреча» отдельно от турнира.

**Таблица участников:**
- Ранг (медали 1–3), аватар, имя, рейтинг, запись `+W =D –L`.
- Сортировка по очкам.
- Отдельная секция **«зарегистрировались, но не пришли»** с теми же полями профиля.
- Блок **арбитр / организатор**.

**Статистика вечера (ориентир этапа 2, не блокер MVP):**
- Счётчики: сыграли, впервые за доской, партий, белые:чёрные.
- Гистограмма состава по рейтингу до встречи (новички отдельно, у них `1200?`).
- Scatter «сила игры vs рейтинг» (точка только если ≥ 3 партий).

**Для нашего клуба берём в MVP:**
- Статусы мероприятия и бейдж на карточке (ТЗ 3.3).
- Итоговая таблица с рангом, именем (по приватности), рейтингом, очками/партийной записью.
- Явная фиксация неявок (BR11, A07) — список «не пришли» после события.
- Разделение «рейтинговый турнир» и «свободная игра» внутри одного вечера, если админ так завёл (у нас уже есть rating_policy на турнире).
- Организатор на карточке события.

**Откладываем / этап 2:**
- Share cards «мой вечер» (07) — сильная идея для удержания, но не в критерии успеха MVP; записать в Deferred или этап 2.
- Сложные графики силы игры и гистограммы состава.
- Интеграция электронных часов и подсчёт ходов/флагов.

### Рейтинг новичков `1200?`

У референса provisional рейтинг отображается с вопросом. Для нас это вход в **Q04** (LCC Rating): нужно решить, как показывать игроков без достаточного числа партий (отдельный бейдж «новичок», provisional значение, скрытие до N партий).

### Навигация

Референс: Игры / Сейчас / Рейтинг / Часы / Профиль.  
Наш ТЗ: Главная / События / Рейтинг / Профиль.

«Сейчас» (live турнир) и «Часы» — отдельный продукт VibeChess, в наш MVP не входят (раздел 20 ТЗ). Профиль у них визуально связан с QR/CODE — у нас это усиливает S07 (членская карта с QR) как точку в профиле или отдельный быстрый доступ.

### Визуал

Референс = тёмный high-contrast + жёлтый CTA.  
Наш = Modern Heritage; тёмная тема — вопрос Q25. Композицию карточек и иерархию (фото → мета → CTA) переносим, палитру и тон — нет.

## Партия 3: профиль, PWA, приватность (файлы 13–21)

### Профиль (13, 14, 17–20)

**Структура профиля у референса:**
1. Аватар + редактируемое имя + город.
2. Реферальная карточка «позовите друга — баллы».
3. Две плитки: рейтинг (`1200?`) и трофеи (`0/80`).
4. Баннер установки PWA.
5. Меню: редактировать профиль, язык, настройки, чат сообщества, поддержка.

**Редактирование профиля:**
- Фото: загрузить / удалить.
- Ник, Chess.com, Lichess, ссылка на соцсеть, «о себе».
- **Сфера деятельности** с пояснением «видят только администраторы» и текстом про закрытые турниры с коллегами — почти один в один наш кейс юристов.
- Toggle **«Показывать мой Telegram»** (игроки смогут написать в личку).
- Блок FIDE/ФШР: фамилия, имя, отчество, ID ФИДЕ, код ФШР, пол, дата рождения, звание, федерация (RUS).
- Кнопка «Сохранить».

**Для нашего клуба берём в MVP (S15 / фича 17):**
- Сводка: аватар, отображаемое имя, LCC Rating (и статус членства / номер — у нас важнее трофеев).
- Баннер установки PWA после первого входа (P02), можно скрыть.
- Меню: редактировать профиль, язык (даже если в MVP только русский — UI готов), настройки уведомлений, поддержка / политика ПДн, выход.
- Фото профиля (с удалением).
- Профессия / специализация: **видна только администрации по умолчанию**; расширенная видимость — по флагам Q03.
- Toggle видимости Telegram / контакта.
- «О себе» и необязательные внешние ссылки (в т.ч. внешний рейтинг со ссылкой на источник).
- Ссылка на закрытый чат — только если Q14 решён и человек действительный член.

**Не берём:**
- Реферальная программа баллов (приглашения выдаёт администрация, фича 8).
- Трофеи 0/80 как игровая мета (этап 2 / вне scope).
- Обязательный сбор даты рождения, пола, полного ФИО «под официальный рейтинг» — противоречит минимизации ПДн и разделу 20 ТЗ (нет официальной сертификации). ID ФИДЕ/ФШР только как необязательные поля внешнего рейтинга.
- Публичный городской чат как открытый пункт меню.

### Установка PWA (15, 16) — прямой референс для P02

**Выгоды на экране:** своя иконка · вход один раз · без адресной строки; после установки открывается вне Telegram.

**Гайд для iPhone (5 шагов):**
1. Открыть страницу в **Safari** (другие браузеры на iPhone не ставят).
2. В адресной строке нажать «⋯».
3. «Поделиться».
4. «На экран Домой» → «Добавить».
5. Запустить с иконки и войти через Telegram один раз.

**Кнопки:** «Открыть в браузере телефона» (primary) + «Скопировать адрес» (secondary).  
**Fallback:** если страница открылась внутри Telegram, скопировать адрес и вставить в Safari вручную.

**Для нашего клуба:** почти один в один фича **29** / экран **P02**. Отдельно нужен короткий гайд для Android (системный диалог установки) — у референса на этих скринах только iPhone. Не копируем обещание «работает при блокировке Telegram / без VPN» как главное УТП: у нас основной канал всё ещё Telegram Login + бот; полноценный вход без Telegram — этап 2.

### Язык (21)

- Один выбор языка для **приложения и бота**.
- Текст: «поменять можно в любой момент».
- Список языков с флагами.

**Для нас:** в MVP UI и бот на русском; переключатель и словари закладываем с первого дня (уже в ТЗ). Английский — этап 2 / Deferred. Не тащим десяток языков референса в MVP.

## Партия 4: уведомления, создание события, рейтинг, профиль игрока (файлы 22–43)

### Центр уведомлений (22)

- Empty state: «Пока пусто. Здесь появятся приглашения на партии, пары туров и итоги событий.»
- Баннер установки ради **push на заблокированном экране** — прямая связка P02 ↔ P03.

**Берём для S16:** понятный empty state под наши события (заявка, запись, предложение места, итоги). Баннер push только в PWA / после установки.

### Создание мероприятия организатором (23–30)

Форма «Новая игра» у референса — полный конструктор. Для **A06** берём каркас полей, не весь зоопарк форматов.

**Поля, которые нужны нам:**
- Дата и время, автоназвание из места+даты с ручной правкой.
- Место: название, адрес, ссылка на карту, фото обложки.
- Контроль времени, число туров (для турнира).
- Вместимость («без ограничения» или N → запись закрывается сама) — уже BR / capacity.
- Описание (необязательно) с подсказками: кого ждут, как найти на месте.
- Toggle **рейтинговый / нерейтинговый**.
- Toggle **свободная игра после турнира** (у нас = отдельная активность или флаг вечера).
- При создании — чекбокс/ссылка согласия с политикой ПДн (для организатора-члена; у админа — по роли).

**Не в MVP:** взнос ₽; выбор формата из 9 типов (арена, 960, bughouse, олимпийка, командная, 1v1); «закрытый турнир» как опция (у нас доступ и так членский); столы/команды.

**Форматы MVP у нас по ТЗ:** шахматный вечер / рапид / блиц / лекция + турнир с rating_policy. Карточки выбора формата можно сделать проще (тип мероприятия), без арены.

### Рейтинг клуба (34, 35, 38)

- Таблица: ранг, аватар, имя, «N турниров · M партий», рейтинг, Δ за период (зелёным).
- Фильтры: период (сезон / всё время), место.

**Берём для S12:** строка таблицы и Δ; простой период (например «всё время» / «этот год») опционально.  
**Не берём:** фильтр по кофейням; обязательную сезонную мету с «осень 2026».

### Профиль другого игрока и история (31–33, 36)

- Сводка: партии, % побед, полоска W/D/L, турниры, лучшее место, медали.
- История турниров и список партий: контроль, дата, цвет, соперник, рейтинг±, результат.
- «Личный счёт · ещё не играли».
- Приватные заметки «видите только вы» (этап 2).

**Берём для S13:** статистика и история с учётом приватности имени; личный счёт между двумя членами — nice-to-have в рамках S13 или этап 2.  
**Не берём в MVP:** заметки о дебютах соперника; тренажёрные ранги.

### Чат клуба и бот (37)

Бот пишет в городскую группу об **отмене турнира**. Для нас: шаблон уведомления об отмене/изменении (раздел 8 ТЗ) + решение Q14, постит ли бот в закрытый чат клуба или только в личку.

### Вне MVP (39–43)

«Сейчас» + тренажёры + спринт + шахматные часы + маркетинговый сторис — подтверждает Deferred, в scope не добавляем.
