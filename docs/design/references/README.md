# Референсы дизайна

Скриншоты аналогичного продукта **VibeChess** / **VibeChessBot** (`@vibechessbot`, vibechess.ru): публичный Telegram бот + Mini App для живых шахматных встреч. Ориентир для сценариев, композиции и навигации. Цвета, шрифты и тон нашего продукта только из раздела 10 ТЗ (Modern Heritage: Emerald / Champagne / Ivory / Graphite). Логотип, название и тексты VibeChess не копируем.

Правило для агентов: референс задаёт композицию, иерархию и сценарий. Не копировать фирменные элементы чужого продукта. Исходники пользователя ещё в `image/`; рабочие копии с понятными именами здесь.

**Сводная карта** «экран ТЗ ↔ референс ↔ фича», библиотека компонентов и список экранов без референса: [../screen-map.md](../screen-map.md).

**Персональные данные на скринах.** На референсах имена, аватары и рейтинги реальных людей. Скрины только для внутренней работы: не публиковать, не переносить в макеты, моки и тестовые данные (там только вымышленные люди), репозиторий держать закрытым.

## Нижняя навигация у референса

| Вкладка VibeChess | Иконка | Есть ли у нас в ТЗ |
|---|---|---|
| Игры | Пешка | ≈ Главная / События (S06, S08) |
| Сейчас | Часы | Нет в MVP (живой ход турнира) |
| Рейтинг | Столбцы | Да, S12 |
| Часы | Шахматные часы | Нет в MVP (отдельный продукт часов) |
| Профиль | QR / CODE | Да, S15 + карта S07 |

**Наша навигация по ТЗ остаётся:** Главная / События / Рейтинг / Профиль. Вкладки «Сейчас» и «Часы» не переносим.

## Визуальный язык референса (не копировать палитру)

- Тёмная тема, почти чёрный фон, жёлтый/золотой акцент на CTA и активной вкладке.
- Крупные карточки с фото площадки, скругления, glass bottom bar.
- Аватарки участников в ряд + `+N`.
- Бейджи статуса: «завершено» (зелёный), рейтинг площадки ★.
- У нас: Modern Heritage, Emerald / Champagne / Ivory / Graphite; тёмная тема опциональна (Q25).
