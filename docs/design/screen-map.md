# Карта экранов: ТЗ ↔ референсы ↔ фичи

Сверка всех 43 референсов (`docs/design/references/`) с экранами ТЗ 1.1 и фичами плана. Для каждого экрана: на что смотреть дизайнеру и агенту, кто строит, чего не хватает.

**Покрытие:** `есть` — референс прямо подходит; `частично` — есть похожий, нужна адаптация; `нет` — референса нет, проектируем по ТЗ.

## Где референсов нет (проектируем по ТЗ)

S03, S05, S14, S17, P04, всё в админке кроме A06, экран ввода результатов, лист ожидания с таймером, гайд установки Android. Это главные места, где дизайнеру и агенту нельзя «подсмотреть», и где нужны отдельные макеты.
